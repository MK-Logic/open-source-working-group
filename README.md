# OSWG

<p>This is the Open Source Working Group (OSWG) GitHub repository</p>


    A process to launch new activities is established to ensure that alignment with the 
    Z-Wave Alliance Open Source mission is maintained and that there is sufficient
    sponsorship available to complete the new activity.
 
    The deliverable process includes key checkpoints to provide design discipline,
    ensure ongoing visibility to the members and assure the quality of the final deliverable.
    
    All Work Items begin as a GitHub ‘Issue’.  Any member of the OSWG can submit an Issue to GitHub for consideration
    by the OSWG for inclusion in the Z-Wave Open Source Project.
```

Following the Work Group procedures the basic workflow is:

Submit an Issue which contains
- A short descriptive name
- Sufficient detail as to what the issue addresses
- Appropriate labels (these will be reviewed by OSWG and may be changed)
- OSWG will assign the issue to the affected project the Issue pertains to
```
